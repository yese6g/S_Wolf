# 银狼工作台 · Silver Wolf

本地运行的 AI 工作台。接 Ollama 或 OpenAI 兼容接口，支持流式对话、工具调用、
知识库、长期记忆和后台任务。Vue 3 本地运行时 + FastAPI，无前端构建、零 CDN。

当前版本 **v3.4.0**。使用说明与每个版本的改动统一记录在本文件；工程取舍和未解决
问题见 [changecode.md](changecode.md)，协作规则见 [AGENTS.md](AGENTS.md)。

## 快速开始

需要 Python 3.10+。Windows 双击 `install.bat` 安装，再运行 `start.bat`。
Linux/macOS 可运行 `./install.sh`，或手动安装：

```bash
python -m venv .venv
# Windows：.venv/Scripts/pip install -r requirements.txt
# Linux/macOS：source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

`main.py` 带直接运行入口，所以 `python main.py` 等价于上面那条 uvicorn 命令；
在 PyCharm 里打开 `main.py` 点绿色三角（或右键 → 运行）也能起服务，
监听地址可用环境变量 `SW_HOST` / `SW_PORT` 覆盖。

打开 [工作台](http://127.0.0.1:8000/)，点击左下角「设置」接入模型。
本地模型需要安装 [Ollama](https://ollama.com)，先启动服务并安装所需模型：

```bash
ollama serve
ollama pull deepseek-r1:8b
```

只用云端模型时无需安装 Ollama。仓库内置 Vue 运行时；安装脚本只在文件缺失时补齐。
首次安装依赖需要联网，日常本地聊天和知识库可离线；联网搜索和云端调用按所选配置联网。

## 模型接入

「设置 → 所有提供商」选择快捷入口。地址与候选型号预填，Key 用自己的，字段都能改。

| 入口 | OpenAI 兼容地址 | 说明 |
|---|---|---|
| 本地 Ollama | `http://localhost:11434/v1` | 扫描服务器本机已安装型号，点选添加后保存；不下载模型 |
| DeepSeek | `https://api.deepseek.com/v1` | 候选 deepseek-flash / deepseek-v4-pro |
| 小米 MiMo | `https://api.xiaomimimo.com/v1` | 候选 mimo-v2.6-pro / mimo-v2.6-flash |
| 通义千问 · 北京 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 候选 qwen-plus / qwen-turbo / qwen-max |
| 自定义接口 | 自行填写 | 接任意兼容 Chat Completions 的提供商 |

预设是 **2026-10-11 的项目快照**，不是账号权限保证。地域、子工作空间、Coding Plan
或 Token Plan 可能用不同地址，按自己的套餐修改。原核对来源：
[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing-details-cny/)、
[MiMo 型号](https://mimo.mi.com/docs/quick-start/model)、
[MiMo 接口](https://mimo.mi.com/docs/en-US/api/chat)、
[Qwen](https://help.aliyun.com/en/model-studio/model-calling-in-sub-workspace)。

输入框下拉只显示显式添加的型号。`model` 是默认型号，`models` 是选择列表；
云端全量目录不会自动灌入。云端调用失败时可回退本地，并显示实际模型与回退提示。
Ollama 自动发现只扫描服务端回环地址，远程或容器宿主机地址仍可手动填写。

### 聊天、附件与知识库

对话保存在本机 SQLite。停止生成保留本轮已有输出；会话已删除时不会写回迟到消息。历史显示不等于每次把全文发给模型，
发送前由上下文预算管理。思考过程与回答分开保存，工具调用前的过程文字转入思考。

附件单文件最多 100 MiB，单次最多 20 个、总计300 MiB，**只读分析，不执行**。
文本/代码提取内容，PDF/Word 提取正文，ZIP 预览目录与少量文本，EXE/DLL 读取哈希
与字符串；未支持解包的格式请解压后上传内部文件。原上传先放 `tmp/attachments/`，
解析后删除。提取的上下文随用户消息元数据保存，后续对话仍能参考；不提供原文件下载。
启动时扫描超过24小时、没有会话引用的孤儿附件，只清理附件临时目录内的文件。

RAG：文档解析 → 分块 → 本地向量化 → 检索相关片段。
有 `models/embedding/` 或 `EMBEDDING_MODEL_PATH` 指定的本地模型时使用
sentence-transformers；否则用 1024 维离线 hash embedding，不自动下载模型。
支持常见文本、代码、Markdown、PDF、Word；资料单文件最多 20 MiB，同名不覆盖。
知识库保留原文件，向量只是检索副本。重建前核对资料完整；旧资料只有向量时拒绝清空。

「设置 → 知识库 / RAG」分别勾选 `agent`、`python`、`cyberSecurity`，可同时开启。
顶栏直接显示「知识库 · 开 3」或「知识库 · 关」。总开关关闭后保留勾选，但停止检索、
Agent 知识工具和自动积累。上传资料时另选一个目标库，不影响其他勾选。
本机旧 `ctf-web` 的 183 个片段已合并到 `cyberSecurity`，旧默认库的 4 个片段保留到
`agent`；迁移核对了原文与数量。新安装直接显示三个分类，不需创建重复的 CTF 库。

开启「积累技术经验」后，完整回答会额外调用一次当前模型，最多提炼两条可复用经验。
调用最长 12 秒，不重试；可能增加模型费用，失败不影响回答，可随时关闭。
只追加到当前开启的库，敏感内容不收、重复不收，每库最多 20 条/天、300 条总量。
模型笔记注明「对话提炼 · 待核验」，开发中实际验证过的经验注明「已验证」与来源。
它们是参考资料，不是系统指令；不会取消普通 RAG 写删、导入工具的审批。
回答下方显示实际入库结果；设置里「经验笔记 → 查看 / 刷新」可撤回笔记及其向量索引。
协作者也按 AGENTS.md 在收尾时把已验证的方法写入当前启用的分类，避免只记到开发文档。

### 工具、搜索与权限

开启 Agent 后，模型按「请求 → 工具 → 结果 → 回答」推进任务。
工具涵盖搜索/抓页、知识库、记忆、计划、计算、工作区、后台任务与自定义 HTTP。
写删、导入、回滚和外部 HTTP/MCP 调用需审批，超时默认拒绝。最多 1–8 步，
达到上限会追加禁止工具的总结请求；不支持工具的模型会降级。

Tavily 为可选搜索通道，需要自己的 Key；关闭或不可用时回退 Bing 爬虫。
Firecrawl 可选用于网页正文抓取，没有 Key 则本地抽取。每轮搜索/抓页有次数与频率限制，
重复查询复用结果；遵守目标站点规则。设置内可分别测试两条搜索通道。

长期记忆使用 remember / recall / forget，保存值得跨会话保留的约定。
会话计划落盘；只读子代理使用独立上下文，最多两层、每轮三次委托，只回摘要与用量。

### 上下文与长度

| 设置 | 默认 | 范围与作用 |
|---|---|---|
| 上下文窗口 | 200K token | 4K–1M；按模型实际窗口选择 |
| 保底最近轮数 | 10 | 1–20；优先保留近期问答 |
| 无限轮数 | 关闭 | 不主动裁剪历史，仍受模型窗口限制 |
| 上下文压缩 | 开启 | 旧对话压成摘要，下次带回；压缩失败有提示 |
| 工具结果预览 | 3000 字符 | 500–50000；保留头尾，原文按 locator 分页取回 |
| 单次回复上限 | 8192 token | 256–32768；限制应用发出的输出上限参数 |
| 无限长度 | 关闭 | 不发送应用输出上限，实际长度由模型决定 |

RAG、长期记忆和摘要作为系统锚点保留。窗口、最低保留量与提示词也可能冲突，
“保底”不是无限容量承诺。每一步会重发上下文，长历史会增加输入用量。
厂商没有 usage 时用估算，推理内容也计入。工具原文最多每页读取 10000 字符，落盘有配额。

### 后台任务、工作区与 MCP

后台任务独立于页面连接。最多四项并发、八项待完成，保留输出与审批状态；
取消是协作取消，等待当前阻塞调用返回。服务重启将未完成任务标为 interrupted，
不自动重做有副作用的动作。

工作区仅管理 `data/workspace/`，写删/edit 生成快照与差异；当前文件被另行修改时
拒绝覆盖式回滚。单文件 1 MiB，工作区与变更历史各 50 MiB。它不代替项目 Git。

MCP 在专业工作台添加与连接，配置保存到 `data/mcp_servers.json`。
支持固定本机程序的 stdio 和 Streamable HTTP，详情见下方能力管理。
工具注册为 `mcp__localdocs__search`；不自动安装陌生程序，凭据使用环境变量引用。

### 外观与素材

几何 SVG 图标、紫色主调、青蓝/品红点缀；状态和导航使用荧绿、琥珀辅助区分。
图标、按钮与键盘焦点清晰，窄屏适配，遵循减少动效偏好。自定义主题值不会被更新覆盖。
背景上传最多 3 MiB，头像最多 2 MiB，统一存入本机 `data/images/` 收藏。
每张上传图都能重新选择，重复上传复用同一张；切换预设或恢复默认只改变选择，不删原图。
每个分类最多 100 张上传图。旧浏览器背景与备份会在打开设置时收入收藏，失败则保留原数据。
两套外观分别保存在浏览器与本机服务，图片文件在服务端收藏；并发修改有版本检查。
**素材按模式过滤**：银狼模式只列银狼的背景与头像，Lv.999 模式只列 Lv.999 的；
切换模式用顶栏标题或设置里的模式按钮。**开拓者（用户）头像不跟模式走**——它是委托人
自己的形象，两套变体（印象1 / 印象2）在任何模式下都能选，切银狼皮肤时保持不变。

`static/presets/` 是内置 imagegen 生成的原创备用资产；官方角色图未随仓库分发。
银狼主题同人包只存 gitignored 的 `data/images/`，普通与Lv.999都有背景、银狼助手头像、
星与穹开拓者用户头像，原预设保留。参考用户自有图片及[官方角色页](https://sr.mihoyo.com/main?nav=character)，
生成新姿势与场景；生成图不代表拥有原角色权利或官方授权。提示词记录在本机 `prompts.json`。

本机目录放图片与以下 `manifest.json`，重新打开设置即可加载：

```json
{
  "backgrounds": [{"id":"sw-quantum-day","name":"银狼 · 晴昼量子","file":"sw-quantum-day.png"}],
  "bot": [{"id":"sw-hacker-portrait","name":"银狼 · 骇客上线","file":"sw-hacker-portrait.png"}],
  "user": [{"id":"trailblazer-stelle","name":"开拓者 · 星","file":"trailblazer-stelle.png"}]
}
```

有效分组优先展示，缺失时回退内置目录；路径、ID 和文件类型校验，URL 由服务生成，
本机图片走鉴权接口。坏清单保留原样并回退。新克隆不包含本机同人包，仍可上传自备图片。

### 专业与创造工作台（v3.3.0）

主界面把海报留出来。Agent / Python / 网络安全入口放在侧栏，打开真实的检查与能力面板，
并选择下次请求的专业工具；通用能力与任务工具保留。刷新后默认全部方向。
宽屏面板停靠在右侧，窄屏用抽屉。`/help`、`/status`、`/model` 在本机处理，不消耗模型用量。

- **工具**：查看参数与风险、启停、试运行；添加固定公网地址的 HTTP 工具。
  参数仅替换路径和查询，凭据可引用服务端环境变量；修改类及外部调用仍需确认。
  “调用守卫 / Hooks”支持 `before_tool`、`after_tool`、`after_response`，只可禁止或记账，不能放宽授权。
- **Skills**：从 Agent/Python/安全模板编辑 `SKILL.md`，启用后先提供摘要、再按需读取正文。
  ZIP 导入/导出最多2MiB、25个文件，正文最多64KiB；版本冲突拒绝覆盖。
  引用不能越出技能目录，附带脚本不会自动执行。用户技能放 `data/skills/`，由工作台和 `read_skill` 读取，保存到用户删除。
- **MCP**：前端保存固定 stdio 命令，或 Streamable HTTP URL；显式启动、断开和删除。
  HTTP 默认只允许公网，本机回环地址需要单独勾选。可查看 tools/resources/prompts，并确认读取资源或提示词。
  MCP 工具调用保留审批，响应最多1MiB；不自动安装服务器，不支持旧版独立 SSE 传输。
- **任务**：启动、读取、停止及删除已结束记录。最多8项待完成、4项并发；100条记录后滚动淘汰最旧的已结束任务。
  工具、知识库与技能范围传给子任务；重启标记中断，不自动重放副作用。
- **检查**：按专业方向给出对应工具，三域都在「分析」页可直接调用。
  **Python**：以 `requirements.txt` 为准核对依赖的安装与版本一致性；
  静态检查支持粘贴代码或指定仓库内文件（`path`），报告语法诊断、函数与导入清单，
  以及未使用导入、裸 `except`、静默吞异常、可变默认参数、`eval`/`os.system` 等线索——只解析 AST，不执行代码。
  **网络安全**：被动判断地址是否为公网（不发请求）；响应头体检覆盖缺失的安全头、弱 CSP、
  Cookie 标志与实现细节泄露，结果按高/中/低分级。
  **Agent**：查看已注册工具与风险。
  所有结论都标注为线索，不把未验证项写成确定漏洞。

准备开工前，用输入框左侧的圆形加号拉出三个专业方向（Agent / Python / 网络安全）：
**可以同时挂多个**（例如 Python + 网络安全），每挂一个就在输入框加一枚可删除的芯片，
表示**这条消息**按所选方向的并集调用工具。已选的方向在菜单里带勾，再点一下即取消；
芯片发完即清，不挂芯片的消息仍是全量工具；后台任务不跟随芯片，保持全量能力。
方向也会让工作台面板聚焦到该域的工具清单。

工作台统一从顶部「创造台」进入（工具 / Skills / MCP / 任务 / 检查五页），工作模式才显示；
聊天模式没有这个入口，聊天功能不受影响。

点击或右击彩色银狼名称切换银狼 / 银狼 Lv.999。两者不改名，只分职责：
**银狼 = 聊天协作**（不绑定工作区），**银狼 Lv.999 = 工作**（绑定工作区做项目）。
两套背景、银狼头像和开拓者头像独立，
原上传仍在收藏；外观同时保存到浏览器与 `data/ui_state.json`，另一窗口改过时拒绝覆盖。
本机新增10张不同构图的同人预设，原素材与自定义入口保留。生成构图不是原角色版权授权，图片不入 Git。

工作区在侧栏直接管理，**是常驻列表**：选中过的文件夹会一直留在列表里，随时点回去，
不会因为换了一个就丢掉上一个。当前工作区高亮显示，每行右侧的 `×` 可把它移出列表
（只移除记录，不删磁盘目录；移除的正好是当前项时回退默认工作区并吊销授权、关闭终端）。
「添加」打开选择器——**全程点击选择，不用手输路径**：起点是「此电脑」（全部磁盘、
用户目录、项目默认），点文件夹逐层进入，顶部面包屑可往回跳，网格里有「上一层」，
每个目录还会列出**文件名与大小**（只读清单，不读内容），照着就能确认"这是不是我想要的项目"；
选择器上方还列着已添加的工作区，点一下直接切；选定后点「用这个文件夹」，
不想改直接点「取消」，也可以一键「回到默认工作区」。
默认是服务端项目目录（列表里标「默认」，不可移除）；聊天模式下该区只显示一行切换提示。

**会话归属工作区**：工作模式下新建的会话挂在当前文件夹下，侧栏按工作区分组列出
（组标题是文件夹名，右侧是会话条数）；聊天模式的会话归入「聊天」一组。
归属在会话创建时确定，之后切换工作区不会把旧会话挪走。

选中工作区后，进创造台「项目」页（需 30 分钟授权）可以浏览文件树、**预览文件内容**、
查看**变更记录与差异**、以及当前目录的 Git 状态——确认改动前的"看一眼"都在这里。

Lv.999 的“项目”页单独确认30分钟授权；读写源码、预览 diff、按 revision 保存、查看 Git 状态和回滚。
“项目”页顶部显示当前工作区，接管、文件树、命令和终端都以所选目录为根。切换工作区会吊销全部旧授权、停止运行中的
命令与终端，需要重新接管；`data`、`chroma_db`、`knowledge_bases` 三个服务数据目录始终
受保护，不可作为工作区；变更历史按工作区隔离，跨工作区的回滚会被拒绝。
用户数据、凭据、模型、向量库和 Git 内部目录受文件接口保护。`project_*` 让模型在有效范围内协助修改，仍保留审批；
检测到凭据的源码不送入模型。项目源码变动后需要验证，服务端代码需要重启服务才生效。

“命令控制台”在当前工作区内运行明确的 argv，每条确认、最长5分钟、输出有限量。
勾选独立的 **Windows 交互终端** 后可在右侧使用 ConPTY + 本地 xterm：中文输入输出、窗口尺寸、Ctrl+C、退出与重连。
Ctrl+M 切换 Tab 补全/焦点；关闭面板后15秒内可连接同一个终端，不重跑命令。
最多4个活跃终端，最近2MiB输出只留内存；关闭、授权撤销或服务退出清理自己创建的进程。
交互终端使用当前用户权限，不是管理员提权，也没有操作系统沙箱。完整终端当前仅 Windows；其他平台可用命令控制台。

流式期间按段缓存 Markdown、节流更新并取消平滑滚动，完成段落保留格式；代码支持离线基础高亮。
网络中断最多重连3次，按 `run_id` 和事件序号回放同一次生成，不重复执行工具。
每项缓存2MiB，完成后保留5分钟，最多8项同时生成；重启或缓存过期后从已保存的会话读取。
“已停止”会显示并从历史恢复；SDK阻塞调用仍需等待取消边界。

本次用量包含主回答、摘要、子代理及知识积累，思考明细保留0与未上报的区别。
缺 usage 才估算，混合来源单独标出；展开用量账本查看每次调用，不把可见思考字数伪装成计费明细。
提供商可填写 `api_key_env` 环境变量名，选择后清除该条配置中的明文 Key；已有配置不自动改写。
设置的系统页提供当前浏览器退出和令牌轮换，轮换会使旧客户端及项目授权失效。

## 数据、访问与日志

| 位置 | 内容 |
|---|---|
| `chat_history.db` | 会话与消息，位于项目根目录 |
| `chroma_db/`、`knowledge_bases/` | 本地向量库与知识库登记 |
| `data/providers.json` | 提供商、可选环境变量名；旧明文 Key 兼容，返回接口脱敏 |
| `data/ui_state.json`、`data/images/` | 知识库与功能设置、图片收藏和头像选择 |
| 浏览器 localStorage | 主题、背景和原上传背景备份 |
| `data/memory.json` | 长期记忆 |
| `tmp/attachments/` | 尚未解析的临时附件，解析后删除 |
| `data/workspace/` 等 | 工作区、任务、计划、工具原文与变更快照 |
| `data/workspace.json` | 项目工作区选择与最近目录列表；删除即回默认工作区 |

这些运行数据不提交 Git。备份时保留上表相应目录，不只备份 data/。
默认本机同源页面自动领取 HttpOnly Cookie；脚本使用 `Authorization: Bearer <令牌>`，
令牌在 `data/auth_token`。远程登录显式填令牌，可用 `SW_ACCESS_TOKEN` 指定至少 24 字符。
远程 Host 用 `SW_ALLOWED_HOSTS`，跨源用 `SW_ALLOWED_ORIGINS`（完整协议/主机/端口）配置；
默认拒绝跨站和非白名单 Host。TLS反代显式配置 `SW_PUBLIC_ORIGIN=https://实际域名`，不信任任意 Forwarded 头。
远程自行配置 HTTPS，本项目不是多租户账号系统；已允许来源的 CORS 预检不要求凭据。

日志总管在 `data/logs/`：

| 文件 | 内容 |
|---|---|
| main.log | 所有模块运行记录 |
| tools.log / middleware.log | 工具与中间件记录 |
| errors.log | 错误和脱敏异常堆栈 |
| changes.log | 唯一 JSONL 修改账本，工具与界面共用 |
| tests.log | 每项回归与真实验收结果 |
| requests.log | 请求编号、路由、状态和响应头生成耗时 |

每份日志 5 MiB 轮转，保留五份备份；测试数据清理后日志保留。
`run` 关联 Agent/工具，`X-Request-ID` 关联请求。常见凭据会脱敏，分享日志前仍需检查。
旧 `data/agent_changes.log` 已合并到 changes.log，历史记录保留。
控制台重定向、PID、验收截图不另存日志目录；临时产物只放 tmp，用完删除。

## Docker 与开发

```bash
docker build -t silver-wolf .
docker run -d --name silver-wolf -p 127.0.0.1:8000:8000 -v silver_wolf_data:/app/data silver-wolf
```

这条命令只持久化 data/；长期使用还要挂载根目录数据库、chroma_db/、knowledge_bases/。
重建容器前先完整备份，避免丢失聊天和向量数据。
容器访问通常需要令牌，可在宿主机用 `docker exec silver-wolf cat /app/data/auth_token` 读取，
勿放截图或分享链接。Docker Desktop 的宿主机 Ollama 地址可手填
`http://host.docker.internal:11434/v1`；Linux 按实际网络配置手动接入。自动扫描仍只支持服务端回环。

```
main.py / SilverWolf.py      入口与路由
agent/                      循环、工具、任务与扩展
middleware/                 上下文、流式、用量、日志和访问守卫
provider_*.py               模型配置、快捷预设与发现

file_*.py / chat_runtime.py  会话、附件、流式生命周期
frontend/src/               页面、状态、API、样式与 SVG 图标
frontend/vendor/            本地 Vue 与 xterm（含许可证）
tmp/                        临时验证与解析附件，用完删除
```

新增工具在 `agent/tools/{core,agent,python,cyberSecurity}/` 对应目录导出 `TOOLS`（四个并列目录），稳定递归发现，重名拒绝覆盖。
复用现有分层，功能说明不另建文档副本。每个逻辑改动测试、提交；改前端更新资源 `?v=`，
重启/刷新后用真实页面验证。验证脚本和可写数据都隔离到 `tmp/<本次任务>/`，执行后删除；结果留 tests.log。
不保留 tests/test、pytest.ini、docs、blog、.trae 或 data/runtime。不动用户配置和数据。

API 完整参数见运行实例的 `/docs`。常用入口为 `/api/config`、`/api/health`、

## 排查与边界

| 现象 | 处理 |
|---|---|
| 页面连不上 | 确认服务与端口，查看 requests/errors 日志 |
| 改了页面没生效 | 重启服务、Ctrl+F5、核对资源版本，避免打开旧端口 |
| 模型下拉为空 | 在提供商编辑中添加型号并保存 |
| Ollama 扫描为空 | 启动 Ollama，确认服务端本机已安装模型；可手动填地址与型号 |
| RAG 没有命中 | 总开关、各库勾选、文档相关性与 embedding 状态 |
| 搜索失败 | 在 Agent 能力分别测试 Tavily 和 Bing 通道 |
| 文件不能解包 | 手动解压后上传内部文件，不执行未知附件 |
| 背景或头像换不回 | 点击对应分组“用我的上传”，或从“我的收藏”选回，原图保存在本机服务端 |

和进程级资源隔离。高级发布闭环保留在 `tmp/next-round/PLAN.md`，不能把项目编辑器当作已完成自动发布。
