# Silver Wolf 功能说明书

> 版本：v1.0.0 ｜ 更新日期：2026-09-02
> 技术栈：Vue 3（本地运行时） + FastAPI（Python 3.10）

---

## 1. 项目简介

**Silver Wolf（银狼）** 是一个以《崩坏：星穹铁道》角色「银狼」为原型的「工作台式」AI 助手，
人设是星核猎手黑客——冷淡、慵懒、毒舌、傲娇，擅长用游戏化比喻讲解网络安全、渗透、爬虫等技术话题。

v0.7.0 核心升级（工作台式）：

1. **左下角设置弹窗**：左下角齿轮按钮打开双栏设置弹窗（不铺满全屏）——左侧是提供商 / 知识库 /
   系统状态导航，右侧是具体编辑内容，模型与 API Key 一目了然。
2. **模型列表用户自维护**：输入框下拉不再自动灌入几百个模型，默认空列表；在设置里手动添加
   哪几个模型，下拉就只显示哪几个。
3. **RAG / 知识库观感优化**：功能不变，视觉升级（霓虹开关、卡片化、使用中高亮）。

v0.8.0 新增：**聊天附件**——输入框 📎 上传压缩包 / exe / 代码 / Word/PDF 等文件，
随消息一起发给银狼做**静态分析**（解包看内容、提取 exe 字符串与哈希、读代码与文档），只读取、绝不执行。

> 历史版本：v0.6.0 引入多模型提供商管理与输入框切换模型、修复流式输出；
> v0.5.0 完成前端升级 Vue 3（本地运行时，无 CDN）、银狼人设丰富、Markdown 上传。

## 3. 安装与启动

### 3.1 环境要求

- Windows / Linux / macOS
- Python 3.10+
- [Ollama](https://ollama.com)（本地模型服务，需已安装）

### 3.2 安装步骤（Windows 示例）

```bat
:: 1. 创建虚拟环境并安装依赖（全部本地安装）
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

:: 2. 启动 Ollama 服务
ollama serve

:: 3. 拉取本地模型（首次）
ollama pull deepseek-r1:8b
```

### 3.3 前端运行时（Vue 3）

Vue 3 本地运行时已随仓库内置（`frontend/vendor/vue.global.prod.js`），无需单独下载。
若文件缺失，运行一键安装脚本 `install.bat`（Windows）或 `install.sh`（Linux/macOS）
会自动下载；也可以手动下载该文件放到 `frontend/vendor/` 下。

### 3.4 启动应用

```bat
start.bat
```

浏览器访问 **http://127.0.0.1:8000** 即可使用。

> 手动启动方式：
> `.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload`

### 3.5 配置（模型提供商）

**推荐**：启动后在「设置 → 模型提供商」中直接管理——
可添加任意 OpenAI 兼容接口，填写名称 / 类型（本地或云端）/ 接口地址 / 模型名 / API Key，
支持「测试连接」「刷新模型列表」「设为默认」。配置保存到 `data/providers.json`（自动创建，不入库 git）。

日常使用不需要任何环境变量文件；代码中保留的环境变量仅在全新环境首次启动时作为
默认值使用，可忽略。

## 4. 界面说明

```
┌─────────────┬──────────────────────────────────┐
│  侧边栏     │  顶栏 (模型徽标/RAG)               │
│  ─────────  ├──────────────────────────────────┤
│  [新开一局]  │                                  │
│  会话列表    │          聊天区                   │
│  · 会话1 ✎🗑 │       (消息气泡 / 欢迎页)          │
│  · 会话2 ✎🗑 │                                  │
│             ├──────────────────────────────────┤
│             │  输入区 (模型下拉 + Enter 发送)     │
│             │  设置按钮(齿)位于左下角             │
└─────────────┴──────────────────────────────────┘
```

### 4.1 侧边栏
- **新开一局**：开始新对话（v2.2.0 起文案，图标为像素加号）
- **会话列表**：按最近活动排序，点击加载历史
- 悬停出现铅笔（重命名）与垃圾桶（删除）图标按钮

### 4.2 顶栏
- **当前模型徽标**：像素状态点 + 实时显示当前提供商与模型
- **RAG 开关**：开启 / 关闭知识库检索（像素方块图标，开启时点亮）

> 设置入口在**左下角悬浮设置按钮（齿轮图标）**。

### 4.3 聊天区
- 欢迎页展示当前模型与 RAG 状态
- 用户消息靠右（紫色），银狼回复靠左（半透明 + 头像）
- 流式输出时显示跳动光标；回复可附带「RAG 来源」与「回退警告」

### 4.4 输入区
- **模型下拉**：输入框上方直接切换提供商与模型；只显示你在设置里添加过的模型，
  没有模型时显示「未添加模型，使用默认：…」，点左下角设置按钮可添加
- **附件（回形针图标）**：选择文件（zip/rar/7z、exe、py、docx/pdf、图片等）作为聊天附件，
  选中的文件以 chip 形式展示，可移除；只带附件也能发送（自动按「请分析这些附件」处理）
- `Enter` 发送，`Shift+Enter` 换行，自动增高（最高 120px）

### 4.5 设置弹窗（左下角设置按钮）

弹窗为「左侧导航 + 右侧内容」双栏布局，大小适中、不铺满全屏：

- **左侧导航**：模型提供商列表（名称 / 本地或云端标识 / API Key 状态 / 默认星标）、
  「添加提供商」、知识库 / RAG、外观、系统状态
- **右侧内容（提供商）**：显示名称、类型、接口地址、默认模型、API Key、设为默认，
  以及「已添加模型」管理（输入模型名添加、chip 移除）
- **右侧内容（知识库 / RAG）**：RAG 开关、当前知识库、文件上传、知识库创建/使用/删除
- **右侧内容（系统状态）**：Ollama 在线状态、提供商数量、云端配置、embedding 后端、版本
- **右侧内容（外观）**：主题色预设（银狼紫 / 霓虹青 / 赛博绿 / 熔岩橙 / 幽灵蓝 / 绯红）、
  自定义主色取色器、背景图本地上传（≤ 3MB，仅存本机浏览器 localStorage，不上传服务器）、
  银狼/我的头像上传（≤ 2MB，同样仅存本机浏览器）

## 5. 功能详解

### 5.1 模型提供商与智能回退

- 默认使用「★默认」标记的提供商（可在设置中修改）；输入框下拉可随时切换。
- 输入框下拉只显示**手动添加**的模型（设置弹窗 → 提供商 → 已添加模型）；
  新提供商默认为空列表，添加后才会出现在下拉里。
- 云端提供商连接失败、配额耗尽或鉴权失败时，**自动回退到本地 Ollama**，
  并在回复气泡上提示「已自动回退到本地模型」。
- 本地模型不可用时（Ollama 未启动），页面显示清晰中文提示。
- 每条回复底部显示实际生成它的模型名（自动回退后也会更新）。
- 推理模型（如 DeepSeek R1）的思考内容以「💭 思考过程」折叠展示。

### 5.2 聊天附件

- 点击输入框旁的**回形针按钮**选择文件，支持压缩包（zip/rar/7z/tar）、可执行文件（exe/dll）、
  Python 等代码文件、Word/PDF 文档、图片等；单文件 ≤ 100MB、单次 ≤ 20 个。
- 发送后，银狼会收到附件的**静态分析材料**：
  - 文本/代码：直接读取内容；
  - zip：列出包内结构与文件大小，并预览少量小文本文件；
  - exe/dll：SHA256 + 可打印字符串片段（strings）；
  - docx/pdf：提取正文文字；
  - rar/7z 等无法直接解包的格式：提示手动解压后上传内部文件。
- 附件保存在 `data/uploads/`（gitignore），**只做读取分析，不会执行上传的文件**。
- 用户消息气泡会显示附件 chips（文件名 + 大小，悬停可见 SHA256）。
- **删除会话时，其附件文件会一并清理**；同一文件仍被其它会话引用时保留，
  所有引用都删除后才删除物理文件。**重启服务不会清理任何附件**；
  从未发送的残留文件保留在 `data/uploads/`，可手动删除。
- 附件内容读不出来时，银狼会先说明「哈希已核对」再用银狼口吻解释，不会生硬报错；
  docx/PDF/.doc 均有内容提取兜底。

### 5.3 会话与历史记忆

- 首次发送消息时自动创建会话，标题取消息前几个词。
- 每次对话保存在 `chat_history.db`，重启不丢失。
- 发送请求时自动携带最近 **20 条**历史消息作为上下文。

### 5.4 RAG 本地知识库（完全离线）

**工作原理**：上传文档 → 解析文本 → 按 500 字符分块 → 本地计算向量 → 存入 ChromaDB →
用户提问时检索最相关片段拼入系统提示 → 模型结合知识库回答。

**Embedding 后端自动选择**（均在本地，零下载）：

| 优先级 | 后端 | 条件 |
|--------|------|------|
| 1 | sentence-transformers（bge-large-zh） | 项目 `models/embedding/` 或 `EMBEDDING_MODEL_PATH` 有本地模型 |
| 2 | 内置离线 hash embedding（1024 维） | 未找到本地模型时自动启用，开箱即用 |

相似度阈值随后端自动适配（hash=0.2，transformer=0.5）。

**支持的文件类型**：`.txt .md .markdown .pdf .docx .doc .py .js .ts .json .yaml .yml .html .css .sql .java .cpp .c .go .rs .sh .bat .csv .xml`（共 23 种，含 Markdown）

### 5.5 离线说明（无外网请求）

- 前端：`frontend/vendor/vue.global.prod.js` 为项目本地化的 Vue 3 运行时，页面**零 CDN 依赖**。
  该文件已随仓库内置，缺失时一键安装脚本会自动下载。
- 后端：Python 依赖全部通过 pip 本地安装；RAG embedding 本地计算。
- 唯一可选联网项：云端模型（用户手动切换到云端时才发起请求）。
- 可将 `models/embedding/` 目录放置 bge-large-zh 模型文件，获得更高质量的向量检索。

### 5.6 外观与背景图

- 左下角设置按钮 → 外观：一键切换主题色预设，或用取色器自定义主色（点缀色自动搭配）；
  设置保存在浏览器本地，重启不丢
- 界面默认为**像素街机风**（v2.2.0，v2.2.1 精修）：自绘像素图标（无 emoji）、街机 HUD 切角面板、
  扫描线底纹，配色为银狼的蓝紫基调（深空紫黑 `#070413` + 蓝紫 `#7C6BFF` + 青蓝 `#3ED8F0`）；
  开关 / 滑块 / 按钮等控件保持圆润精致（v2.2.1 起）；
  之前保存过自定义主题的浏览器保持原样，不受默认值调整影响
- 背景图支持上传本地图片（JPG/PNG 等，≤ 3MB），只存本机浏览器，不上传服务器；
  「恢复默认」回到纯色背景（默认无背景图）
- 仓库不含任何版权素材（角色图/背景图）；图标全部是代码绘制的像素 SVG；
  如使用第三方图片请确保有使用授权
- 头像同理：默认使用像素狼头标，可在「外观」上传自己的银狼/用户头像
- **头像、知识库选择、RAG 开关均持久化保存**（服务端 data/ 目录），重启服务或换浏览器都不丢

### 5.7 Agent 能力（v2.0.0）

**Agent 模式**：开启后，模型会自己决定「要不要查资料 / 要不要动知识库」，
按「思考 → 调工具 → 再思考」的方式多轮完成一件事（默认最多 4 轮，可在设置里调 1-8）。

内置工具：

| 类别 | 工具 | 作用 |
|------|------|------|
| 联网 | `web_search` / `fetch_page` | 搜索网页、打开网页读正文 |
| RAG | `rag_search` / `rag_list_files` | 检索知识库、列出知识库文件 |
| RAG 维护 | `rag_write_file` / `rag_delete_file` | 新增或修改 / 删除知识库文本文件（自动重新向量化） |
| 自我维护 | `tools_list` / `tools_upsert` / `tools_delete` | 增删改自己的「自定义工具」 |

**自我修改的安全边界**：Agent 只能写知识库文本文件与 `data/tools.json`（工具定义），
不能改代码、配置或其它目录；每次修改都记录到 `data/agent_changes.log`，
可在「设置 → Agent 能力」查看最近记录。

**联网搜索后端**：只有两种 —— **Tavily**（主，需 Key）与**自研爬虫兜底**（免 Key，走 Bing）。
在「设置 → Agent 能力」填 Tavily Key 后可用两个按钮分别自检：测试 Tavily / 测试爬虫 · Bing。
爬虫带浏览器 UA 并限制频率（≥1.5s）。可选填 Firecrawl Key 用于抓取 JS 渲染网页正文
（不填则用 BeautifulSoup 本地抽取）。

**Tavily 开关**：Tavily 按调用量计费，同一张设置卡片里有「启用 Tavily」开关。
关掉后 `engine=auto` 的搜索直接走免 Key 爬虫，不消耗额度；只想用爬虫的话保持关闭即可。

**搜索的用量控制**：Agent 一次最多搜 6 次、抓 6 个网页；每次默认取 3 条结果（最多 5 条）。
同一个查询在一轮里只会真正发一次请求，重复问会直接复用结果。结果会先筛一遍：
AI 导航站/工具农场站被丢掉，厂商官方页面（openai.com、api-docs.deepseek.com 等）排在最前，
同一个域名最多出现 2 条。搜索过程不会写成回答 —— 它只会出现在「思考过程」里，
回答部分是结论与关键数据。

**上下文管理（省 token）**：在「设置 → 上下文」页签里，共五项 ——

| 设置 | 默认值 | 可选范围 | 作用 |
|------|--------|----------|------|
| 上下文窗口 | 200K tokens | 4K ~ 1M | 一次请求最多带多少（人设提示 + RAG + 历史 + 当前提问），超出丢掉最旧的 |
| 保底最近轮数 | 10 轮 | 1 ~ 20 | 窗口再紧也不丢最近这几轮，避免模型断片 |
| 无限轮数 | 关闭 | 开 / 关 | 打开后完全不裁剪，历史一条不丢（token 消耗会明显变高） |
| 工具结果上限 | 3000 字符 | 500 ~ 50000 | 工具返回内容进上下文前截断，避免一次搜索把上下文撑爆 |
| 单次回复上限 | 8192 tokens | 256 ~ 32768 | 模型单条回复的最大长度，防止一次回答吃掉大量额度 |
| 无限长度 | 关闭 | 开 / 关 | 打开后单次回复不设上限（不发送 max_tokens 参数） |
| 上下文压缩 | 开启 | 开 / 关 | 把被裁掉的旧对话压成摘要存本地，下次作为背景带回 |

窗口有两种调法：**拖滑块**（按 8K / 16K / 32K / 64K / 128K / 200K / 320K / 512K / 1M 档位）
或**手动输入**任意数值，两者会互相吸附。窗口不是越大越好 —— 每多留一段历史，
之后每一轮工具循环都会重新计费一次。

打开「无限轮数」或「无限长度」后，对应的滑块与输入框会置灰（说明它已经不参与调节），
关掉开关即可恢复。

调整后立即生效并保存在服务端；想看省了多少，可以观察每条回复底部的输入 token 变化。

**模型选择**：输入框左上角的下拉菜单按提供商分组（💻 本地 / ☁️ 云端），
显示你手动添加的模型；当前使用的模型有勾选标记，点菜单以外的地方即可收起。

**当前时间工具**：Agent 可以在回答前调用 `get_current_time` 获取真实日期、星期、时区与时间戳，
因此「今天/本周有什么新闻」这类问题会基于真实日期判断，而不是猜。

**本轮总结**：每条回复底部显示 token 消耗（输入 / 输出 / 合计，标注「实测」或「估算」）、
工具调用轮数、调用过的工具标签、联网来源（前 3 条 + 展开完整 URL）与 RAG 命中内容；
这些信息随消息保存，刷新或重新打开会话后依然可见。

## 7. 常见问题（FAQ）

| 问题 | 排查 |
|------|------|
| 打开页面报「无法连接后端服务」 | 后端未启动，运行 `start.bat` |
| 发送消息报「无法连接本地模型（Ollama）」 | 启动 `ollama serve`，确认 `ollama list` 中有 `deepseek-r1:8b` |
| 首次回复很慢 | 本地大模型首次加载需数十秒，属正常现象 |
| 上传的 exe/压缩包会被执行吗 | 不会。附件只做静态读取（文本/压缩包内容/字符串/哈希），从不执行 |
| 上传 rar/7z 提示无法解包 | 本机未内置解包工具，请手动解压后上传内部文件 |
| 删掉会话，附件残留会删吗 | 会。会话删除时其附件文件一并清理；被多个会话引用的文件在最后引用删除时才清理 |
| data/uploads 里出现没人用的文件 | 上传后未发送/发送失败会留下孤儿文件；不会自动删除，可手动清理 |
| 历史消息的 Markdown 不渲染 | v0.8.3 已修复：加载历史会话时角色归一化，标题/代码块/列表正常渲染 |
| 背景图/头像的版权问题 | 仓库默认渐变背景、无官方素材；自行通过「设置 → 外观」上传自备/无版权图片 |
| 联网搜索一直失败 | 在「设置 → Agent 能力」填 Tavily Key 或 SearxNG 地址并点「测试搜索」；国内 DuckDuckGo 通常不可达 |
| 回复底部没有 token / 工具信息 | 确认「设置 → Agent 能力」里 Agent 模式已开启；v2.0.0 之前的历史消息没有该信息属正常 |
| RAG 上传后回答不引用知识库 | 检查设置面板 RAG 开关已开启；确认问题与文档主题相关（低于阈值不会检索） |
| 想接入新的云端模型 | 打开设置 → 模型提供商 → 添加提供商，填写接口地址 / API Key / 模型名（须为 OpenAI 兼容接口），点「测试连接」验证 |
| 输入框下拉没有想要的模型 | 点下拉旁的 ⟳ 刷新模型列表；若该接口不支持 `/models`，直接在设置里填写模型名即可 |
| 更换 embedding 模型 | 把模型文件放入 `models/embedding/` 后删除 `chroma_db/` 重新上传文档 |
| 端口被占用 | 修改启动命令中的 `--port` 参数 |

├── knowledge_bases/         # 知识库元数据（自动生成）
├── requirements.txt / .env / start.bat
